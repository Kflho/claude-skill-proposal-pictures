# 文字与符号规范（图内文字）

> 图内文字是**对外承诺**的一部分，规范程度直接影响评审对"这伙人靠不靠谱"的判断。

## 1. 称谓层级：先定后用

中文申报材料里最常见的自相矛盾来自"课题 / 子课题 / 研究内容"混用。开工前先定一张表：

| 层级 | 例（本项目） | 谁在用 |
| --- | --- | --- |
| 上级（项目/课题） | 课题2 复杂电磁环境下高精度定位技术 | 总体组／导师 |
| 本级（本部分） | 本子课题 / 研究内容4 通感资源组网协同调度 | 我们 |
| 下一级（本部分内部） | 4-1 ~ 4-4 研究子内容 | 我们 |
| 兄弟（并列部分） | 研究内容1/2/3（同级的其他部分） | 兄弟团队 |

**规则**

1. 同一层级在一份材料里**只有一个叫法**；导师/总体组定了就跟随，不要自创。
2. 本部分自称统一（如"本子课题"），不要在同段里"本课题/本部分/本项目"乱换。
3. 引用兄弟部分时用**与上级一致的编号 + 全名**，避免歧义（"课题二"在一份稿里既可能指母课题、
   又可能指兄弟子课题——这种歧义一旦出现，改用不依赖编号的写法）。
4. 层级改动（如"课题四"→"研究内容四"）必须**全局替换**并在台账留痕。

## 2. 符号与记法禁用表

| 禁用 | 改用 | 说明 |
| --- | --- | --- |
| `↓≥10%` `↑` | `降低 ≥10%` / `提高 ≥N%` | 箭头是工程口语；与正文逐字一致 |
| `＋` 作连词 | `与` | 全角加号只用于专名：`5G-A＋毫米波` |
| `·` 作并列 | `、` | 与正文顿号一致 |
| `->` `=>` | `→`（仅连线标签/流程带） | 连词位置不要用箭头 |
| `≤10 m@1 km` | `1 km 处定位精度 ≤10 m` | "精度@距离"是自创记法 |
| `100ms` / `10km` | `100 ms` / `10 km` | 数字与单位间加半角空格 |
| `50:50`（写全时） | `固定 50:50 时频划分` | 缩写要能自解释 |
| `>>>`（正式交付图） | `说明：` 或另起小字行 | 仅当上级示例本身用 `>>>` 且要求原样时保留 |
| `~` 表示范围 | `3~8 站`（可）／`-` 连接数字（避免） | 保持一致即可 |

保留的规范符号：`≥ ≤ ＞ ＜ % ℃` 半角数字、全角括号（中文语境）、顿号、破折号 `—`。

## 3. 换行与断句

1. **换行落在词间**：`通信与感知共用同一套 / 时频、空域与功率资源` ✅；
   `…共用同一套 / 时频` ❌（把并列项拆开）。
2. 一个方框内 2~4 行为宜；超过 4 行考虑拆框或缩字。
3. 跨行**必须拆成独立 `<text>`**（各带自己的 `y`），不要用同一 `<text>` 内多 `<tspan>` 靠 `dy`；
   行尾补标点，保证某些不认 `dy` 的查看器里拼起来仍读得通。
4. 中英混排：中文与半角英文/数字之间加半角空格（`支持 5G-A 组网`）。
5. 括号：中文语境用全角 `（）`；纯英文/公式内用半角 `()`；同图统一。

## 4. 缩写与全称

- 首现给全称：`交替方向乘子法（ADMM）`、`第三代合作伙伴计划（3GPP）`；之后可单用缩写。
- 图与正文**各自独立**满足这条规则（评审可能只看图）。
- 不要在图里出现只在正文定义过的缩写而不给全称。

## 5. 图内文字的内容边界

| 应该写 | 不该写 |
| --- | --- |
| 结论性短语、方法名、交付物名、指标（带限定） | 整段论述、文献综述 |
| 与正文一致的术语 | 即兴造词、内部代号 |
| 未定项的"待定/待 XX 给定" | 猜的数值、编的单位 |
| 连线标签写"给了什么" | "相关""有关"这类空话 |
